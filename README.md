# Control de Préstamos

App para registrar hipotecas, autos y otros préstamos, con abonos extra mes a mes, progreso del pago y tabla de amortización completa.

Tus datos se guardan solo en tu dispositivo. Nada se envía a ningún servidor. Usa «Guardar copia» para respaldarlos donde prefieras (iCloud Drive, Google Drive, OneDrive o tu computadora) y «Abrir copia» para cargarlos en otro dispositivo.

## Instalar en iPhone o iPad
1. Abre la dirección de la app en **Safari**.
2. Toca el botón **Compartir** y elige **Agregar a pantalla de inicio**.
3. Después de abrirla una vez, funciona aunque no tengas internet.

## Usar en computadora sin internet
Descarga `index.html` y ábrelo con doble clic en Safari, Chrome o Edge.
